# 자동 중요 영역 선택

큰 사진을 통째로 넣으면 비용이 늘고, 전체 사진만 작게 줄이면 작은 얼굴·글자 정보가 사라진다. Imagen은 전체 구도용 축소본과 중요한 부분의 디테일 참조를 함께 준비한다.

## 선택 과정

1. macOS Vision의 얼굴 사각형, 글자 인식, 물체 중요도, 주의 중요도 분석을 실행한다. 반환하는 것은 위치·종류·신뢰도이며 인식한 문자열은 저장하거나 프롬프트에 삽입하지 않는다.
2. 인접한 글자 영역을 작은 라벨 단위로 합친다. 얼굴에는 머리카락·귀·턱, 다른 물체에는 주변 여유를 둔다.
3. 전체 축소본에 비해 확보하는 세부 해상도, 신뢰도, 토큰 비용으로 순위를 매긴다. 해상도 이득 1.25배 미만은 제외한다.
4. 겹치는 영역을 억제하고 후보 종류와 원본 사진에 다양성 가중치를 적용한다.
5. 원본에서 선택 영역을 먼저 잘라낸 뒤 각각 최대 512로 제한한다. 작은 영역은 원본 픽셀을 유지하고 모델 정렬 여백만 추가한다.

자동 영역은 최대 3개, 추가 비용은 1,536토큰, 전체 참조는 10장 이하로 제한한다. 512×512 한 장은 1,024토큰이다. 전체 구도 참조는 추가 예산과 별개다. 많은 원본을 넣으면 전체 구도 참조 비용도 늘고, 10장 슬롯을 모두 쓰면 디테일 추가가 생략된다.

이미 512 이하인 원본은 추가 해상도를 얻을 수 없어 분석을 생략한다. 적절한 후보가 없으면 구도 참조만 사용한다. 모든 분석기가 실패하면 생성 전에 중단하고, 일부 오류는 실행 로그와 기록에 남긴다. `REFERENCE_REGIONS` 파일이 있으면 수동 지정이 자동 선택을 대신한다.

## 확인한 범위

공개된 [전처리 검증 기록](../benchmarks/data/automatic-selection-2026-10-28.json)은 인물 원본, 합성 제품, 영문 글자, 한국어 글자, 빈 이미지, 회전 방향, 여러 입력 번호 연결을 포함한다. 검증용 제품에서는 물체와 라벨이, 글자 이미지에서는 글자들이 선택됐고 빈 이미지에는 추가 참조가 없었다. 화면 표시나 생성 결과의 육안 검사는 하지 않았다.

분석기가 준비된 상태의 전처리는 사례별 약 0.49~0.81초였다. 시스템 분석기의 첫 초기화에는 약 15~17초가 걸린 경우가 있다. 이것은 전처리 시간이며 최종 생성 시간을 의미하지 않는다.

## 한계

물체는 시각적 중요도에 의한 추정이며 상품 종류나 편집 의도를 이해하는 검출기가 아니다. 배경·전경이 선택되거나 작은 대상이 누락될 수 있다. 모든 글자·인물을 고해상도로 보존하지 않으며 예산을 넘는 후보도 제외한다. 참조 디테일이 좋아져도 최종 생성 얼굴·문자가 정확하다고 보장하지 않는다.
