# 16스텝 디노이징: 블록 재사용 실험

## 조건

M3 Pro 36GB, MLX 0.32.4, FLUX.3 Klein Q8. 512×352 출력, 참조 1320·출력 704·텍스트 240 토큰, 시드 7. 동일한 입력 safetensors를 사용했다. 시간은 가중치 복원과 디노이징을 포함하고 모델 로딩, 텍스트·참조 인코딩, VAE 디코딩, 파일 저장은 제외한다. 각 항목 1회이며 순서·발열·다른 부하의 영향을 받는다. 전체 생성 시간의 감소율이 아니다.

| 방법 | 전체 28블록 계산 | 디노이징 | 기준과 잠재 RMSE | 기준과 RGB PSNR |
|---|---:|---:|---:|---:|
| C++ 기준 재측정 | 16회 | 72.52초 | 기준 | 기준 |
| 직전 블록 변화량 재사용, 스텝 5·9·13 | 13회 | 63.70초 | 0.01356 | 48.93 dB |
| 초반 4스텝 유지, 스텝 5·7·9·11·13·15 재사용 | 10회 | 52.60초 | 0.02954 | 45.34 dB |
| 직전 블록 변화량 재사용, 스텝 3·5·7·9·11·13·15 | 9회 | 45.96초 | 0.14819 | 31.60 dB |
| 직전 두 변화량의 선형 외삽, 위 7회 | 9회 | 46.27초 | 0.14506 | 31.41 dB |

스케줄 업데이트는 모두 16회지만 재사용 스텝에는 joint transformer의 28개 블록을 생략한다. 직전 실제 연산의 joint 출력과 입력의 차이를 저장하고, 다음 입력에 그 차이를 더한다. 결과는 근사치이며 전체 16회 연산의 출력과 다르다. PSNR은 동일 이미지를 기준으로 한 RGB 픽셀 오차 요약일 뿐 얼굴·로고·텍스트의 품질을 보장하지 않는다. 단 한 사진으로 품질 유지나 일반성을 결론 낼 수 없다. 기본 실행기에는 적용하지 않았다.

`approx-residual.cpp`, `approx-residual-half.cpp`, `approx-residual-linear.cpp`와 실행 파일은 이 로컬 실험 디렉터리에 있다. 절대경로가 아니라 이 디렉터리를 기준으로 입력과 체크포인트를 지정해 호출한다. 고정된 스텝 인덱스는 16스텝 실험용이며 일반 API가 아니다.

## 더한 투영 실험

QKV와 MLP 입력의 GPU 투영 가중치를 합쳐 단일 행렬곱으로 처리한 프로토타입은 4스텝 23.54초, MLX 피크 16.47GB였다. 이전 기본 경로의 단일 측정은 19.73초, 12.39GB였다. 출력 잠재값은 비트 일치했으나, 프로토타입이 원본 가중치도 유지해 추가 메모리를 사용했고 단일 측정이므로 병합 방식의 이론적 한계를 의미하지 않는다. 기본 경로에 적용하지 않았다.

단일 큰 joint 블록을 강제 동기화하여 분리 측정하면 QKV 투영 약 29ms, attention 약 16ms, attention 출력 투영 약 10ms, MLP 입력 투영 약 103ms, MLP 출력 투영 약 31ms였다. 동기화는 원래의 CPU/GPU 중첩과 lazy graph를 바꾸므로 이 숫자를 실제 전체 시간의 직접적인 분해나 정확한 점유율로 해석하면 안 된다. MLP 입력 투영이 심층 프로파일링 후보라는 근거로만 사용한다.

## 두 번째 시드

동일한 사진과 프롬프트에서 초기 노이즈만 시드 19로 바꾸고 기본 경로를 먼저, 3회 재사용을 나중에 실행했다. 디노이징은 각각 75.49초와 64.38초였다. 최종 잠재 RMSE 0.01140, RGB MAE 0.451, PSNR 50.00dB였다. 같은 사진의 두 시드일 뿐, 사진·프롬프트·출력 크기·하드웨어 전반의 화질이나 시간은 미검증이다.

## 재현 예시

저장된 시드 7 입력에 6회 재사용 시제품을 실행한다. 첫 4스텝과 마지막 스텝은 항상 전체 블록을 계산한다. 이것은 일반 생성 명령이나 배포 코드가 아니다.

```sh
cd /path/to/Imagen
IMAGEN_NATIVE_OPT=1 IMAGEN_NATIVE_CACHE=1 \
  outputs/analysis-2026-10-28/native-prototype/approx-residual-late \
  "$HOME/.cache/gaon-image/flux3-klein-q8/transformer" \
  outputs/analysis-2026-10-28/native-prototype/parity/edit-input.safetensors \
  outputs/analysis-2026-10-28/native-prototype/parity/reproduced-late.safetensors 16
```

두 번째 시드의 6회 재사용은 52.66초(기준 75.49초 대비 약 30.2% 감소), 잠재 RMSE 0.02731, RGB MAE 0.969, PSNR 45.36dB였다. 시드 7은 52.60초(기준 72.52초 대비 약 27.5% 감소), RGB MAE 1.005였다. 기준과 재사용은 시드마다 각각 한 번 측정했고 일부 순서가 다르다. 비교 대상은 같은 사진 한 장이다.
